# Single-Line Preflight Fixture

This directory is generated by `python3 tools/run_experiments.py`.

It contains a small structural LeRobot v3 fixture and a small `.rrd` placeholder used only to test preflight behavior. The `.parquet` and `.rrd` files here are not training data; they are minimal sentinels that let the reference preflight detect native containers without a WorldEpisode sidecar.
