\title{WorldEpisode: Auditing Silent State Drift in Robot-Learning Datasets}

\author{
  Alba Tellez Fernandez\\
  URDF Studio
}

\date{}

\begin{abstract}
Interactive spatial datasets can be locally valid and behaviorally wrong: every file loads, but the
behavior is not what it seems. A robot log can load while a command is replayed at the moment it was
issued rather than the moment the motor actually executed it; a benchmark can report a strong policy
score while the same reconstructed scene appears in both training and testing; a simulator asset can
render correctly while its collision role, coordinate frame, or content digest no longer matches the
state under evaluation. We call this failure mode \emph{silent state drift}: the bytes are readable,
but the assumptions that make replay, training, or deployment meaningful have quietly drifted.

This paper presents \emph{WorldEpisode}, an executable state-integrity contract for robot-learning
datasets. Rather than adding another file format, it specifies five invariants that any episode must
preserve. LeRobotDataset v3 is the container we evaluate in depth with real, downloaded public data;
Rerun, MCAP, NCore, OpenUSD, and glTF are covered only as lighter binding-retention pilots. The five
invariants are persistent identity, explicit frame and clock mappings, representation roles,
temporal events, and provenance --- each backed by a machine-checkable rule (we call this general
family Universal Spatial State, or USS, but evaluate only the robotics profile in this paper).
Two corpus-level obligations follow from the invariants and carry the headline results:
lineage-disjoint evaluation splits and loss-explicit conversion.

We evaluate WorldEpisode on public robot-learning data. On ArmnetBench's public SO-101
LeRobot release, a random episode split leaks every tested world lineage and yields 0.850 offline
success for a behavioral-cloning probe; a scene-disjoint split reduces measured leakage to zero
(0.000) and the same probe to 0.000. On a real SO-101 trajectory, declaring the inferred four-frame, 133 ms
actuation delay reduces validation joint RMSE from 4.732 to 1.862 degrees, and the same
timestamp-aware action contract reduces same-trace MuJoCo and Genesis replay RMSE from 3.425 to
1.563 degrees. A programmatic LeRobotDataset-to-WorldEpisode-to-LeRobotDataset round trip over ten
public episodes preserves 1,935 state/action rows, timestamps, video timestamp ranges, and
physical-frame records with maximum numerical error 0.0 while reporting source-absent semantics as
explicit conversion loss. The validator detects all 14 injected physical-coherence fault classes.
Deterministic game-engine and autonomous-driving pilots only sketch how the same vocabulary might
extend beyond robotics; they are illustrative, not measured evidence.

The contribution is a tested state-integrity layer and audit protocol for deciding whether spatial
data can be trusted for conversion, replay, evaluation, and deployment. The paper does not claim a
new universal file format, simulator-independent physics, or benchmark score inflation without
policy reruns. ACT/Diffusion rollouts, famous-benchmark reruns, contact-rich simulator comparisons,
Isaac/SAPIEN execution, external adoption, and production game or autonomous-driving audits remain
explicit open gates.
\end{abstract}
