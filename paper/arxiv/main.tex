\begin{abstract}
Spatial-agent datasets can be structurally valid and behaviorally wrong. A robot trajectory can
deserialize cleanly while replaying commands at the wrong effective time; a random split can report
success after leaking the same reconstructed room into train and test; a game or driving replay can
load every asset and sensor log while using the wrong state revision, digest, frame, or clock. We
call this failure class \emph{silent state drift}: the files still load, but the state being trained,
replayed, or deployed is no longer the state the experiment claims to evaluate.

This paper introduces \emph{Universal Spatial State} (USS), a storage-, representation-, and
runtime-neutral sidecar contract for auditing silent state drift. USS does not replace LeRobotDataset,
Rerun, NCore, MCAP, OpenUSD, glTF Gaussian splats, game telemetry, or autonomous-driving logs.
Instead, it specifies the invariants those containers must preserve: persistent identity, explicit
space/time mappings, representation roles, transition and action semantics, temporal events,
provenance, quality records, and lineage-aware splits. WorldEpisode is the robotics reference profile
used to make the contract executable under real hardware traces, robot-learning datasets, simulator
adapters, and real-to-sim assets.

The measured results show why the contract matters. On ArmnetBench's public SO-101 LeRobot release,
a standard random split leaks every tested world lineage and yields 0.850 offline behavioral-cloning
success; a scene-disjoint split drops leakage to zero and the same probe to 0.000. On a real SO-101
trajectory, modeling the inferred four-frame, 133 ms action delay reduces validation joint RMSE from
4.732 to 1.862 degrees, and a tested MuJoCo replay drops from 3.425 to 1.563 degrees. Active
LeRobotDataset-to-WorldEpisode-to-LeRobotDataset conversion across two public datasets preserves ten
episodes and 1,935 rows with maximum numerical error 0.0 while marking source-absent physics rather
than inventing it. The validator detects all 14 injected fault classes and the independent fixture
failures. Across seven pilot bindings, native containers preserve only 17--39\% of the audited
\texttt{uss-core-23} projection, while WorldEpisode sidecars recover that projection for
dataset/log/world bindings.

The contribution is therefore not another file format. It is an evidence-gated invariant layer that
makes hidden state assumptions testable before training, replay, or deployment. The current results
remain deliberately scoped: ACT/Diffusion rollouts, same-trace second-runtime replay, famous-benchmark
score-inflation proofs, and production game/AV audits are exposed as open gates rather than claimed
outcomes.
\end{abstract}
