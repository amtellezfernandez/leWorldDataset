\section{Controlled Experiments}

We evaluate the contract with deterministic controlled experiments in the public repository. The
suite isolates failure modes that larger robot experiments often hide: conversion loss, invalid
physical semantics, timing drift, world-frame augmentation, and lineage leakage.

\paragraph{RQ1: semantic preservation across bindings.}
We implement executable export/import artifacts for seven bindings. Each binding writes a native
payload and a WorldEpisode sidecar, then the experiment reimports both and checks exact equality
against a 23-field semantic projection. Table~\ref{tab:binding-retention} shows that common
containers preserve only 17--39\% of the contract natively, while the sidecar recovers all fields
for dataset/log/world bindings. A Gaussian asset binding alone preserves only 17\% natively and
30\% with limited sidecar metadata, confirming that an asset format is not an episode--world
contract. The LeRobot binding targets the current v3 storage layout rather than the initial dataset
format described when the LeRobot library paper was submitted~\citep{lerobot,lerobot_v3}.

\paragraph{RQ2: physical-coherence fault detection.}
We inject 14 faults into the baseline package, including missing clock domains, incomplete
cross-clock mappings, unknown frames, missing transform intervals, unknown event entities, missing
representation roles, digest errors, action-contract omissions, non-content-addressed worlds,
missing delta sequences, missing provenance, and missing quality records. The validator detects all
14 expected requirement failures with 1.000 recall and 0.933 precision. We also evaluate two
hand-authored independent fixtures, both of which trigger the expected diagnostics. The single
false-positive requirement is useful rather than harmful: removing an action reference frame
triggers both \texttt{ACTION.001} and the downstream \texttt{FRAME.001} reference check.

\paragraph{Public LeRobot frame check.}
We include an offline mirrored first frame from \path{lerobot/svla_so101_pickplace}. Its six
joint values have maximum magnitude 98.924 in degrees and 1.727 after radian conversion; treating
degrees as radians would therefore violate the action/state unit contract. The corresponding
SO-101 end-effector position \([0.1044,-0.00242,0.07292]\) m is within a 0.5 m workspace bound.
From the same mirrored frame we materialize a 10-frame LeRobot-style episode artifact with nine
actions, command timestamps, effective timestamps, and a declared 20 ms latency model. This artifact
is used as the recorded-episode fixture for timing and action-contract checks.

\paragraph{RQ3: declared replay timing.}
We replay a deterministic grasp-and-transport trace with a two-step declared actuation latency. The
declared-latency replay obtains object-trajectory RMSE \(0.00395\), while naive command-time replay
obtains RMSE \(0.01422\), a \(3.6\times\) improvement. A second engine parameterization under the
same declared assumptions obtains RMSE \(0.00668\), illustrating replay within a tolerance envelope
rather than bit-identical physics.

\paragraph{RQ4: synthetic counterfactual robustness.}
We evaluate a shifted-camera/object-displacement regression task. Observations-only nearest-neighbor
control succeeds on 0.292 of shifted test cases. Adding unstructured 3D side information increases
success to 0.342. WorldEpisode-style world-frame identity and counterfactual camera augmentation
increase success to 0.592 over 120 deterministic test cases.

\paragraph{RQ5: lineage-safe splits.}
We generate episodes with world/entity lineage labels and evaluate a memorization policy. A random
episode split leaks every tested world/entity pair and obtains 1.000 accuracy. World-disjoint and
entity-disjoint splits have zero measured leakage and reduce memorization accuracy to 0.500 and
0.562 respectively. This pilot demonstrates why split manifests need lineage constraints.
