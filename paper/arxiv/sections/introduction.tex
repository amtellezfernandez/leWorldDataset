\section{Introduction}
\label{sec:intro}

Robot-learning data can be structurally valid yet behaviorally wrong. A tensor can have the expected
shape but an undeclared unit; a command timestamp can be mistaken for motor-effective time; an asset
can retain its appearance while losing its collision role; or an episode-level split can put related
world captures in both training and evaluation. Each artifact still loads, so ordinary schema and
container checks miss the failure. We call this class \emph{silent state drift}: the stored
observation, action, asset, or split no longer denotes the physical state assumed by training,
replay, or evaluation.

Robot learning is a demanding test case because it combines asynchronous control, multi-camera
recordings, reconstructed scenes, simulator exports, and policy evaluation. LeRobot integrates
collection, datasets, policies, and deployment~\citep{lerobot}; LeRobotDataset v3 stores state,
action, timestamps, video, and episode indexes~\citep{lerobot_v3}. Rerun and NCore cover multimodal
logs and pose conventions, while OpenUSD and glTF describe worlds and assets~\citep{usd,ncore,gltf_gs}.
These containers are complementary, but none by itself proves that the same entities, frames,
clocks, action semantics, asset roles, and source lineages survive conversion.

\paragraph{Related work.}
Documenting datasets is not new. Datasheets for Datasets~\citep{gebru2021datasheets} and model
cards~\citep{mitchell2019modelcards} standardize prose descriptions of provenance and intended use; MLCommons
Croissant~\citep{croissant2024} adds a machine-readable metadata layer for ML-ready datasets; and
Open X-Embodiment~\citep{openx} aggregates robot data under a shared schema. Evaluation leakage is a
well-documented driver of the reproducibility crisis in ML-based science~\citep{kapoor2023leakage}.
WorldEpisode differs by making cross-container assumptions executable. It binds each episode to an
immutable world revision and closed identity, frame/clock, representation-role, event, and
provenance graphs; a fail-closed validator reports stable requirement IDs, and each conversion emits
machine-readable loss. It is a sidecar contract over existing containers, not a replacement format
or dataset card.

\paragraph{Contributions.}
\begin{enumerate}[leftmargin=1.4em,itemsep=2pt,topsep=3pt]
  \item An executable state-integrity contract with five coupled graphs, JSON Schema, semantic
  validator, conformance fixtures, and fail-closed LeRobot/Rerun preflight.
  \item Loss-explicit LeRobot conversion, including exact round trips over
  \ExpConversionScaleEpisodeCount{} public episodes from \ExpConversionScaleDatasetCount{} datasets
  and a
  versioned binding-retention audit.
  \item Empirical audits of a task--scene-proxy split and action timing, with episode-level
  uncertainty intervals and explicit boundaries for the confounded split, single-controller
  telemetry, same-trace and contact-rich simulator replay, and controlled proxy experiments.
\end{enumerate}
