\section{The Sidecar Contract, Made Executable}
\label{sec:contract}

WorldEpisode delivers the contract as a sidecar blueprint around existing formats. It does not ask
a LeRobot dataset to become a USD scene, or a USD scene to become a policy-training table. Instead, it records the relationships those
containers need in order to agree about the same state: the state revision, persistent entities,
space/time conventions, transition contract, asset roles, interaction events, provenance, and split
lineage. The sidecar is not a mandate to package a global robot corpus as millions of small
folders: the single-episode record is the semantic unit, and production datasets add a manifest
layer (namespaces, URI resolvers, shard catalogs, materialized indexes, split manifests,
append-only snapshots) so that opening a corpus starts from the manifest and its indexes rather
than from a recursive storage scan.

Native containers continue to store the arrays, video, logs, worlds, and assets for which they were
designed. The sidecar stores only the relationships otherwise scattered across loader assumptions,
making cross-container identity, timing, role, lineage, and conversion loss checkable.

\subsection{Runtime adapters}

WorldEpisode is not tied to a single rendering or physics engine. A runtime becomes a trusted
target by implementing an adapter that preserves the same semantic invariants and emits replay
evidence, which keeps the integration direction clean: datasets are not rewritten around
simulator-native assumptions; simulators compile their scene loading, action interfaces, and replay
reports against the sidecar. The adapter contract has three layers:
\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=3pt]
  \item \textbf{Invariant interface}: ingests immutable world revisions, frame and clock graphs,
  entity identity, representation roles, action channels, asset digests, provenance, and quality
  records.
  \item \textbf{Asynchronous schema extension}: lets an engine register cloth, deformable, fluid,
  articulation, material, or procedural-scene extensions without weakening the core episode record.
  \item \textbf{Deterministic replay accountability}: records runtime identity, version, solver,
  timestep, actuator parameters, initialization state, command/effective timing, latency, tolerance
  envelopes, and measured drift.
\end{itemize}

The current implementation includes tested minimal MuJoCo~\citep{mujoco} and
Genesis~\citep{genesis} replay adapters
for the same LeRobot control-loop trace. The Isaac
mapping is emitted but untested, and SAPIEN remains adapter-required. The claim is therefore not
simulator-independent physics but runtime-neutral accountability: every simulator reports against
the same state contract, so cross-runtime drift becomes measurable rather than hidden inside loader
conventions.

\subsection{The executable robotics profile}
\label{sec:profile}

\paragraph{Complete action semantics.}
An action vector is not portable without its operational contract. Each action channel must declare
actuator, control mode, parameterization, reference frame, units, absolute/delta/velocity semantics,
limits, command rate, command timestamp, effective timestamp, latency model, interpolation,
normalization, gripper semantics, and missing-value policy. A vector such as
\([0.01,0,0,0,0,0,1]\) is otherwise ambiguous: it could be a tool-frame delta, base-frame delta,
velocity command, normalized policy output, or delayed target increment.

\paragraph{Implementation artifact.}
We implement the contract as four executable components: a JSON Schema for structural validity, a
machine-readable conformance requirement file, an installable semantic validator, and a round-trip
experiment runner. The validator maps each diagnostic to a stable requirement identifier such as
\texttt{TIME.001}, \texttt{FRAME.002}, or \texttt{ASSET.002}. The experiment runner takes a
WorldEpisode package, exports binding-native artifacts plus sidecars, reimports them, compares a
versioned semantic projection, injects controlled faults, and writes reproducible result artifacts.
The projection itself is published as \path{conformance/projections/uss-core-23.v0.json} and
validated against \path{schemas/semantic-projection-v0.schema.json}. The contract is represented
independently in the public schema and validator rather than only in its initial implementation.

\paragraph{One-line preflight.}
The validator is packaged as \texttt{worldepisode}. A blocking preflight can be run from the shell
with \texttt{worldepisode preflight <dataset-or-manifest>} or from a training script with a single
Python call such as \texttt{preflight\_lerobot(dataset.root).raise\_if\_failed()}. Native LeRobot
folders and Rerun \texttt{.rrd} recordings are recognized directly; without a WorldEpisode
manifest or sidecar, they fail closed on missing world revision, entity identity, representation
role, action timing, frame/clock, split-lineage, and conversion-loss controls. This makes the
semantic audit a pre-training check rather than a separate post-hoc documentation exercise. The
repository pairs the validator with converters, leakage and replay tools, a clean-room reader, and
a runtime adapter report; Section~\ref{sec:evidence} presents what each one measures.
